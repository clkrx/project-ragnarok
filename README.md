First part in a Norse themed set of AI agents. Huginn is the first agent primarly for the foundation, with many to come.

Huginn - huginn deals with basic tasks around the computer, including PowerShell commands, light web fetching through serper, perform file operations such as creating new files and moving them around, and take actions in websites autonomously. 

Muninn - This is the 2nd iteration of Huginn. This takes huginn's core base and adds more in-depth features, including memory, screensharing and screen recording for remote task execution, and a new discord bot user interface. This is designed to make it more accessible remotely and more of a seamless iteration

V3 (name to come at a later date) - This will be a big iteration. It will start with Voice control and the option of  running local models to increase speed and cost at it's discretion, depending on the depth of the task. I will also add advanced orchestration with sub agents and let the ai, if needed, potentially make it's own light tools if needed by coding it's own tools (Potentially).
